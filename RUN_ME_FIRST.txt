VOICEDESK - LOCAL SETUP (WINDOWS)

1. Open PowerShell in the folder containing app.py.
2. Install dependencies:
      python -m pip install -r requirements.txt
3. Create a local environment file:
      Copy-Item .env.example .env
4. Add your Gnani key to .env:
      GNANI_API_KEY=your_key_here
   Speech recognition and spoken replies require a valid key. Keep .env private.
5. Start VoiceDesk:
      python -m streamlit run app.py
6. Open the local URL printed by Streamlit. The Type / sample tab works without
   an API key; use the audio tabs with a valid key.

Optional: set LLM_BASE_URL, LLM_API_KEY, and LLM_MODEL in .env to enable LLM
review. Run tests with:
      python -m pip install -r requirements-dev.txt
      python -m pytest -q

Stop the server with Ctrl+C in PowerShell. Never commit or share your API key.
